# Gilgamesh themes

One folder per theme: `colors.toml` (the palette) and optionally `backgrounds/` (wallpapers
that come with the theme). Pick one in Gilgamesh Settings → Theme, or `qs ipc call theme set <name>`.

`jellybeans` is Gilgamesh's own palette, `rose-pine` is the official Rosé Pine (main) palette. The other palettes come from Omarchy
(https://github.com/basecamp/omarchy, MIT license, Copyright (c) David Heinemeier Hansson),
same key names, so Omarchy themes can be dropped in as they are.
